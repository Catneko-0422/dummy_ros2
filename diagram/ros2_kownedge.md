| 名稱                       | 功能                          | 類比                |
| -------------------------- | ----------------------------- | ------------------- |
| **Node（節點）**           | 執行單位，像是一個程式或模組  | 一個 App            |
| **Topic（主題）**          | 發布/訂閱通訊機制，傳遞資料流 | 電台頻道            |
| **Publisher / Subscriber** | 負責發送/接收資料             | 主播 / 聽眾         |
| **Service（服務）**        | 請求-回應通訊模式             | 打電話問問題        |
| **Action（動作）**         | 可中斷、持續回報的長任務      | 點外送 → 可追蹤進度 |
| **Parameter（參數）**      | 儲存可設定的變數              | 設定值              |
| **Launch file**            | 啟動多個節點的設定檔          | 開機自動啟動腳本    |
| **rclcpp / rclpy**         | C++ / Python API              | 語言介面            |
